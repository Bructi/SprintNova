Frequently Asked Questions

You can register for any open event by clicking the "Register Now" button on the event card. This will open the registration link (usually a Google Form) in a new tab.

The medal tally is calculated automatically. Each event winner is assigned a Gold, Silver, or Bronze medal. These medals are then aggregated to show totals for each class (e.g., SE COMP A) and each department (e.g., Computer Engg.).

All fests and events are open to all bona fide students of Xavier Institute of Engineering. Some specific events may have prerequisites (e.g., "open to SE and TE only"), which will be mentioned in the event details.
